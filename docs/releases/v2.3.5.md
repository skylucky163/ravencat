# RavenCat v2.3.5

这次加入 DeepSeek 对话导入、AI 回收站和长文本转 TXT，也扩展了生图连接与模型参数设置。

## 聊天

- **导入 DeepSeek 对话**。在目标 AI 的单聊「更多 → 对话导入」粘贴 DeepSeek 官方 ZIP 导出的下载链接，搜索并选择一段对话导入。导入会读取导出时的当前分支及其可读取的附件。
- **长文本粘贴转 TXT**。单聊和群聊都可以开启，超过设定阈值的粘贴文本转为待发送附件。可以分页查看 TXT、Markdown 正文，也可以完整复制。
- **查阅历史资料**。AI 可以按需回查聊天附件与通话记录。历史 TXT、Markdown 在上下文中保留文件引用，正文可按需读取。
- 单聊和群聊增加停止回复按钮。搜索结果可以直接收藏，玻璃主题调整输入框和引用布局，修复超长消息气泡边缘与 Markdown 代码块间距。

## AI 与模型

- **AI 回收站**。在「设置 → 数据管理 → AI 回收站」查看删除的 AI，七天内可以恢复，也可以确认后彻底删除。
- **主理与记账关系**。AI 可以提交主理或记账申请，由用户确认。主理 AI 获得相应授权后，可以设置 Android 系统闹钟。
- **生图**。新增可灵 Image 4.0，支持从已有服务导入自定义生图连接，并逐项检测参数。生图图库支持按名称检索、改名和删除记录。
- **模型参数**。支持强度参数的思考模型可选自动或六档强度。Temperature 和 Top P 留空时使用服务商默认值。

## 修复与验证

- 整理前台与悬浮窗口的消息交付和已读通知，修复部分 SQLite 升级时重复加列导致的中断。
- 自动化回归覆盖对话导入、附件、回收站、消息交付、SQLite 迁移和生图协议。Android 单测覆盖设备控制、通知、原生长文本粘贴和悬浮层。
- 下载和导入需要可用的 DeepSeek 官方导出链接。生图模型、参数和参考图能力由服务商决定，使用配置的服务可能产生费用。

## 安装

- 支持 Android 13 及以上。更新前可在「设置 → 数据管理」导出本地备份。备份包含聊天数据与明文服务凭据，请妥善保管。
- GitHub 发行版提供 `RavenCat-2.3.5.apk`、`RavenCat-2.3.5-third-party-notices.zip` 和 `SHA256SUMS.txt`。源码依赖、许可和素材来源见[第三方软件声明](../third-party-notices.md)。
