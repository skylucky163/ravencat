# RavenCat v2.3.0

本次更新加入用户与 AI 生图、聊天代码卡与作品库、固定重复日程和朋友圈编辑，同时整理模型连接、数据管理与图片查看体验。

## 新功能

- **AI 生图**：在「发现 → 实用工具 → AI 生图」选择模型并生成图片，成功后保存到系统相册。接入硅基流动、MiniMax、豆包 Seedream、阿里千问和 OpenAI GPT Image，按模型展示可用参数与参考图入口。AI 可使用同一模型选择生成私有图片，再通过既有图片工具查看或发送。
- **代码卡与网页预览**：回复中的代码块独立显示，保留原始缩进与换行；完整 HTML 可在应用内预览，其他语言可查看和复制源码。代码尚未生成完整时不开放运行。
- **作品库**：可手动收纳代码作品，按封面网格查看、修改名称或更换封面；AI 可查询、收纳和编辑自己创作的作品。源码、收纳关系和封面进入完整本地备份。网页运行进度不保存。
- **重复日程与未回复跟进**：支持每天、每周和每月重复，并在未来日期预览后续安排；可在伴随设置开启未回复跟进、设置间隔。可单独移除系统日历事件，保留应用内部日程。
- **朋友圈编辑**：用户和 AI 可编辑自己的动态，修改正文、图片及可见范围，保留原发布时间、评论和点赞；用户可管理图片描述与重新识别。
- **官方工具扩展**：扩展 Kimi 官方工具，并接入 DeepSeek 官方搜索与网页抓取。相关工具需要对应官方接口和显式授权，使用所配置账号的服务额度。

## 使用体验与修复

- 服务配置支持分组和多个独立命名的 API Key，统一模型连接选择；固定提供方可按相同地址快捷填入已有 Key。删除连接时解除对应引用，保留角色、模型和聊天历史。
- 新增「数据管理」页面，集中展示备份与恢复、清空数据入口；「最近删除」仍为未开放的占位，暂不提供找回功能。
- 完整本地备份补齐 MCP Token、AI 请求诊断配置和最近记录；更新备份帮助中的凭据与隐私说明。
- 统一全屏图片查看器，聊天图片可保存到系统相册；改进收藏关键词搜索、改名后的作者显示及文字收藏的思维链保留。
- 修复中断回复的正文操作与选字复制，保留代码块和长段落的完整边界；统一表单、模型选择、按钮反馈和底部弹窗的键盘布局。
- 修复时刻社交摘要遗漏事件时间，以及 Metro 扫描临时目录和原生构建产物的问题。

## 使用范围

- 支持 Android 13 及以上。模型、生图与外部工具需要自行配置服务和凭据，可能产生供应商费用。
- 生图参数与参考图能力以所选供应商和模型为准；旧自定义生图配置保留记录，需要新建受支持供应商的配置后使用。
- 用户保存到系统相册的图片不进入应用内部备份，恢复出厂或卸载应用不会随之删除这些图片。
- 备份包含模型 API Key、联网搜索 Key、MCP Token 等明文凭据，以及可能含私密聊天的诊断记录，请妥善保管。

## 安装

- 下载 `RavenCat-2.3.0.apk` 安装，沿用公开版包名和发布签名，可覆盖更新；更新前建议导出本地备份。
- 许可与素材来源见 `RavenCat-2.3.0-third-party-notices.zip`，附件校验值见 `SHA256SUMS.txt`。
