# 聊天代码卡与网页预览

## 内容与分段

Chat 的回复分段器拥有 Markdown 围栏边界。普通正文仍按当前单气泡／多气泡策略交付；反引号或波浪线围栏始终独立为一条 assistant 消息，前后的说明文字保持原位置。围栏内不按空行、分号、句末标点或长度分泡，保留源码的缩进、换行和空白。更长围栏可以包住较短围栏。

流式快照与最终提交使用相同的分段器。尚未收齐的围栏标记暂不作为普通正文交付；已闭合消息不重新排段、不修改身份。主题关闭多气泡时也不跨代码卡合并前后说明文字，列表键包含该区间的首条消息身份。

未闭合代码显示生成中或未完成卡片，不自动补代码、不开放运行。围栏闭合只表示代码块传输边界完整，不保证 HTML／JavaScript 没有错误。历史消息不在迁移中重新切分。

## 卡片与导航

消息列表只渲染最多四行、420 字符的源码摘要，不挂载网页容器，也不把完整源码交给 Markdown 或原生 Text 排版。卡片使用既有业务卡片的气泡表面、主题与长按入口；保留复制、选择文字、引用、多选、分享和删除等已有消息操作，禁用正文改写、翻译和普通收藏。重写与历史版本仍是整轮回复的既有操作。

完整 HTML 卡片点击打开网页；其他语言点击查看源码。卡片通过导航 context 表达预览 ID，Host 将其映射到 Expo Router 的 `/chat/code/[previewId]`。源码不进入 URL 参数。

预览页右上角用代码／网页图标切换视图，旁边的书签图标操作收纳；导航栏按操作区预留等宽侧栏，长标题单行省略，不覆盖按钮。网页与源码使用同一份快照；在本页查看源码时保留当前网页实例，离开预览页释放实例。完整源码连续显示于同一个 Android 原生文字选区，保留缩进和换行，支持跨任意行选字复制与全文复制，不按字符数或行数拆成多个部分。完整源码仅在用户打开源码视图时排版，聊天列表仍只渲染卡片摘要。

## 源码快照与事务

`chat_code_previews` 保存预览 ID、作者 Agent ID、语言、原始源码、标题、可运行标记、创建时间和可空的来源消息 ID。可预览范围是 HTML／HTM 围栏及明确以 HTML 文档开头的无语言围栏，不编译 React、Vue 或其他工程。

完整 HTML 在正式消息插入事务中保存，回合提交失败一起回滚。预览 ID 沿用消息的稳定 client identity；没有 client identity 的正式消息使用数据库消息 ID。用户在 T3 前打开已闭合代码时，由显式打开命令保存快照；T3 绑定正式来源，不创建第二份源码。其他语言在用户打开时保存查看快照。

源码快照独立于聊天来源。删除消息只清空来源外键，保留已保存源码、作者身份与 ID；恢复出厂随业务表清除，完整数据库备份自然包含源码与收纳关系。

后续聊天的原文窗口、摘要输入与跨会话背景只携带已提交网页的作品引用：稳定 ID、生成时名称和按需读取提示，不重复携带完整 HTML。当前名称与收纳状态从作品工具查询；改名不改写消息或源码中的 `<title>`。未完成代码、尚未提交的流式代码和其他语言保留原有上下文语义。

## 作品库与版本选择

AI 主页与聊天「更多」都由 App 导航到 `/assistants/[aiId]/works`，打开当前 AI 的同一个作品库。两个 Feature 只接收导航回调，不持有彼此实现或页面路径。

网页预览右上角的书签图标只操作 `chat_code_library` 收纳关系，已收纳时显示带勾的书签与主题强调色。生成与打开网页不自动加入；再次点击已收纳书签或在作品库选择「移出」只删除收纳关系，不删除消息、源码或其他版本。之后可以再次打开原预览并加入。相同预览 ID 的重复加入由主键裁决，重复设置不改变原加入时间；移出后再次加入使用新的加入时间。

每次生成仍保留独立源码快照，同名网页也可分别收纳。不根据标题、正文相似度或相邻消息猜测新应用／优化版本，不覆盖之前选中的版本，不增加应用血缘与自动版本号。用户与具有工具权限的作者 AI 可以选择哪些快照出现在作品库，网页存档仍未实现。

作品库列表以双列封面网格展示，按真实作者和收纳关系读取卡片摘要与封面文件名，不加载全部完整源码、不运行网页。封面在收纳瞬间由预览页截取当前网页画面（react-native-view-shot，Android 必须截带 `collapsable={false}` 的包裹 View）；截图失败时展示真实错误原因，收纳本身不受影响，用户可在作品库卡片点「换封面」从相册选图（4:3 裁剪）替换。封面由 application 层落在 persistent-media 根的 `covers/chat-code/` 目录，随媒体根归档进备份；DB 只存文件名，列表通过本层解析可加载地址。备份 create 与 restore preflight 都校验快照引用的封面文件真实命中，缺失即拒绝缩水备份。正在查看源码时网页不可见，收纳不附带封面；无封面时网格退回占位图标。封面文件属于收纳关系：移出作品库或被新封面替换时，在 commit 成功后定向删除；事务失败时清掉已落盘但无引用的文件。预览页修改收纳状态不会更换 WebView 的源码输入或实例，当前交互画面保持。保存失败保留上次确认的收纳状态。列表获得焦点时读取事实并订阅 commit 后的收纳变更，失焦释放订阅；先返回列表、后完成的保存也能刷新，迟到的旧读取不能覆盖新版本。

数据库 172 新增收纳表，并为 171 的源码快照增加作者字段；只从仍存在的来源消息回填作者，不猜测已删除来源的归属。173 为收纳表增加封面文件名列。174 清空旧私有目录里的封面引用（未归档文件无法迁移），由下次截图或上传重建。升级不自动收纳任何旧网页，事务失败整笔回滚。

## AI 作品工具

Host 的 `codeWorks` 工具包装配四个工具，沿用统一授权和角色视觉设置，不另建作品状态或工具执行流程：

| 工具 | 参数与行为 |
| --- | --- |
| `list_code_works` | `scope=saved/unsaved/all`，默认作品库；每页 20 条作品 ID、名称、创建时间与收纳状态，使用 `nextOffset` 翻页，不读取源码。未收纳与已移出的快照均可找回。 |
| `get_code_work` | 按 `work_id` 读取原始源码，每页最多 5000 个 Unicode 字符，`page` 从 1 开始，返回总页数和 `nextPage`；默认第一页携带封面，`include_cover` 可显式控制。 |
| `set_code_work_in_library` | 按 ID 和 `included` 显式加入或移出；原 ID、名称、源码与消息保留，重复加入保留原收纳时间和封面。后台调用不运行网页或自动截图，没有封面时明确回告。 |
| `edit_code_work` | 必传 ID，`title` 与 `media_asset_id` 至少传一项，可一起修改；作品名最多 80 字符。改名支持未入库快照；封面要求已入库，按真实图片居中裁剪为 4:3、压缩落盘。 |

所有查询只返回当前 AI 真实作者身份下的作品；写入在业务事务内重新裁决作者归属与当前运行资格。图片解码、裁剪和落盘在事务外，名称与封面引用同事务提交。处理图片时作品被移出、运行失效或写入失败，整次编辑不提交，清理刚落盘但无引用的文件；旧封面在 commit 后定向清理。

读取只使用当前保存的封面文件，即用户上传、AI 上传或收纳时成功截取的真实图片，不重新运行网页、不用占位图或其他图片替代。未保存封面返回 `missing`；文件缺失、不可读或所选视觉模型不可用返回 `unavailable` 与明确提示，源码页仍可正常读取。只有成功的视觉观察才携带 `modelImages`；选择视觉识别模型时沿用其文字识别结果，失败不自动切换路线。动态图上传只取单帧。

## 运行边界

网页只在预览页的 WebView 内运行；模型 HTML 位于仅允许脚本的不透明来源 iframe，不取得同源权限、弹窗、顶层导航、下载或表单提交能力。CSP 在模型内容之前设置，允许内联脚本／样式和 HTTPS 资源，禁止嵌套网页、插件、文件和任意基础地址；WebView 关闭文件访问、定位、第三方 Cookie、DOM 存储与缓存，不接入 RN 消息桥。

HTTPS 图片、字体、脚本和网络请求可以加载，实际能否访问取决于资源端的网络与 CORS 策略。网页的按钮、画布和页面内交互在当前实例中运行，不保存 localStorage、Cookie 或游戏进度；依赖持久存储的网页需要后续单独设计存档契约。

## 验证

`npm run verify:chat-code-preview` 覆盖代码独立分泡、任意字符增量边界、未闭合代码、CRLF、长围栏、源码逐字复制、菜单资格、主题合并、快照事务、170/171/172/173 升级、手动收纳、自定义封面与落盘失败清理、同名版本隔离、来源删除后保留、再次加入，以及操作收纳不重载网页。`verify-http-exchange-diagnostics.mjs` 校验备份 create/restore preflight 对封面引用的严格检查；`verify-assistant-profile.mjs` 验证两个作品库入口的实际导航；`verify-chat-agent-display-integration.mjs` 验证单／多气泡的流式投影经 T3 后保留相同身份与完整 HTML，并保存唯一快照。

同一命令还运行 `verify-chat-code-work-tools.mjs`，通过真实 SQLite 验证作者隔离、作品列表与源码分页、真实封面观察、缺失提示、重复入库保留封面、名称与图片原子编辑、事务取消、并发移出时清理，以及聊天／摘要统一作品引用。

Android 卡片触摸、原生源码选区与真实长列表帧率仍需包含 WebView 原生依赖的安装版本验收；TypeScript、桌面浏览器和内存 SQLite 验证不替代真机结果。
