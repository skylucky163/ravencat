# 模型设置自动保存契约

## 范围与交互

AI 个人主页的角色模型设置、辅助模型中心的已有资产编辑、群聊管理员设置采用自动保存。角色模型正式路由为 `/assistants/[aiId]/model-settings`，更多菜单保留直达同一页面的入口，旧 Chat 设置地址仅重定向。流式输出和多气泡本轮保留原对话设置的入口、字段及生效规则，模型页不新增对应控件。
辅助模型新建保留显式「创建」，不在空表单里生成资产。
AI 个人主页的名称、人设、头像与对话设置的上下文可见条数、多气泡回复，提交规则见 [个人主页与对话设置自动保存](conversation-settings-autosave.md)。角色模型设置不编辑这些资料或对话偏好，重置只影响 Temperature、Top P 与 Max Tokens。

- 文字输入在失焦时提交；停输不触发保存。数字键盘提供「完成」，模型设置支持点击空白或滑动收起键盘。
- 开关、模型选择和参数预设立即提交自己的字段，不顺带提交尚未失焦的文字草稿；重置默认参数只更新其拥有的参数。
- Temperature / Top P 复用 `shared/ui/SliderField`，范围和步长由页面传入；拖动只展示预览，松手或手势中断才把最终值立即提交给表单，手动数字输入在失焦时提交。
- 正常保存安静完成，无保存按钮、常驻保存状态或成功弹窗。
- 校验失败显示字段下方红色小字及红色边框，保留用户输入；合法字段仍可提交。
- 写入失败显示区域错误与重试入口，保留草稿，不自动循环重试。
- 返回（包括 Android 系统返回）或前往其他设置页先提交；存在未保存错误时留在当前页，展示错误并提供「恢复已保存值」。
- 切到后台提前提交有效修改；无效草稿和错误仅由当前页面内存保留，不新增持久化草稿。
- 连接测试独立于保存；已保存不等于网络连接可用。新配置供后续请求使用，不改变已开始任务的配置。
- 连接测试只验证当前配置的一次响应，不额外探测工具支持、不自动改变工具权限。仅返回思考或因输出额度截断也已证明接口可达，不扩容重发；工具权限始终由用户的独立开关决定。

## 所有权与提交

Assistants 拥有角色模型配置与辅助模型资产。页面负责输入草稿、提交节奏、错误展示和离开行为。
独立角色模型入口复用 `useAIAssistantProfile` 与原 `AIModelSettings`，不依赖当前聊天或创建会话。Host 通过原有插槽装配 Chat 的视觉模型选择，模型页内的自动保存和返回仍只有一个所有者。提交事实由聊天 Shell 自行订阅，不通过旧设置路由回填配置。
更新命令只接受对应配置字段的增量；不得提交整份 AIProfile，或顺带覆盖名称、人设、身份及其他入口的数据。
辅助模型的 metadata 是一个关联配置组，校验并提交完整组；与其无关的合法字段独立保存。
翻译资产的提供方、连接字段与 metadata 共同组成关联组，切换提供方必须填完有效连接后才提交；名称独立保存。提供方输入契约归 Integrations，Assistants 的表单和资产解析共用该契约。
未修改字段不提交；明确清空辅助模型 Key 提交 null，不继承旧 Key，测试也不回退到旧 Key。
SQLite 继续经过 databaseCoordinator，提交后才更新页面投影或发布现有模型变更信号。
页面更新回调同样只确认本次提交的字段；主理关系命令只通知身份变化，不携带整份 AIProfile 回填模型配置。

群聊管理员的草稿校验位于 Chat presentation：Temperature 为 0～2，Top P 为 0～1，Max Tokens 为正整数或「无限制」，上下文消息数量为 0～100 的整数。
Temperature / Top P 可留空并保存为 null；新增群聊默认留空，持久化与管理员规划请求不回填本地数值。
非法输入原样保留，显示红字与红框，不静默返回、不截断小数、不回填默认值。管理员配置命令信任该输入契约，Repository 只写入增量字段，写入与确认共享事务。
API 地址、Key 和系统提示词按原有可空契约提交；清空时只清空本字段，不带走其他配置。模型选择与数字预设立即提交，文本失焦提交。语音页手输模型名称与下拉选择分开表达提交时机。

## 输入与确认

页面区分当前草稿与已确认的输入。每次提交固定自己的输入快照。
通用草稿确认与页面离开规则位于 shared/ui；业务字段解析仍由各页面负责。
保存期间的新输入保留，旧提交的完成只更新已确认值，不重设当前输入。
写入依次完成，期间的修改合并为后续增量；不会把数据库调度误当成草稿版本控制。
失焦的 `commit` 固定触发当时的草稿快照，不抢先提交写入期间的新输入；返回和后台的 `flush` 排空当前有效修改。立即控件以已确认或已请求提交的快照为基础，只推进本次修改字段，关联配置组仍由 Feature 的解析契约提交。
外部刷新只同步没有本地修改的字段，不覆盖未提交草稿。
无效数字不自动变成默认值；合法的可空参数按当前契约表示 null。
角色模型的 Temperature / Top P 可留空，保存为 null；读取和连接测试保留该语义，请求不发送对应字段，由服务商决定。新角色与角色模型参数重置采用留空，旧角色的已保存数值不自动改写。留空时输入框保持空白，保留无填充、无滑块的轨道，可直接拖动设值；字段下方提示「留空使用服务商默认值」。显式填写 0 仍是有效数值。

## 验证要求

行为验证覆盖迟到确认、新输入、恢复已保存值、无效字段与合法字段同时编辑、写入失败与重试、清空 Key、关联 metadata 校验。
SQLite 验证确认增量更新不覆盖人设和名称；不新增源码形状断言。
完成 TypeScript、改动文件 ESLint 及相关边界检查；不构建 APK。`npm run verify:assistant-settings` 补充独立角色模型入口、Host 插槽、目标隔离和路由返回的迁移验证。
群聊管理员行为验证使用 `node --no-warnings scripts/verify-group-admin-autosave.mjs`；`verify-group-speech-claim.mjs` 覆盖管理员配置的真实 SQLite 增量、并发和上下文 consumer。

服务管理的名称与连接组分别提交；名称编辑不携带旧连接快照。模型保存时的自动收录与模型引用共享事务，连接测试不收录服务。各用途资产不再保存启停草稿；自动收录开关属于服务列表的独立偏好。
