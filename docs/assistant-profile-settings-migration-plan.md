# AI 个人主页布局与设置归属

状态：本轮页面调整与自动验证已完成，真机体验待确认。日期：2026-11-01。

本轮按用户最终确认的范围实施：摘要和上下文各自共用同一个页面；流式输出和多气泡暂不调整，待查看其余页面效果后再讨论。此前的流式双入口规划不属于当前实现。

## 1. 主页布局

从上到下：

```text
xxx 的主页
资料卡：头像、名称（昵称）、xxx 的设定预览
        卡片右上角编辑图标
模型设置
上下文设置
聊天摘要
xxx 的朋友圈
```

头像、名称和设定位于同一张卡片；头像、名称居中。设定显示前 300 个 Unicode 字符，超出时追加省略号，完整内容仍在既有独立编辑页查看和修改。卡片编辑图标是资料编辑入口，顶部栏不重复提供文字编辑按钮。

名称与昵称继续分字段保存，没有昵称时只显示名称。设定为空时明确显示未填写，不补造人设。编辑页仍按原规则自动保存头像、名称、昵称和设定，不因布局变化复制数据。

朋友圈复用既有 AI 作者筛选、头像和默认封面，只调整主页的顺序和标题。

## 2. 入口与归属

| 能力 | 主页 | 更多 / 对话设置 | 实际目标 |
| --- | --- | --- | --- |
| AI 资料 | 卡片编辑图标 | 更多保留个人主页入口 | 原独立资料编辑页 |
| 模型设置 | 保留入口 | 更多原入口保留 | 同一个既有模型设置页 |
| 上下文设置 | 独立入口 | 对话设置原控制区替换为一行入口 | 同一个 `/assistants/[aiId]/context-settings` |
| 聊天摘要 | 新增入口 | 更多原入口保留 | 同一个 `/chat/[aiId]/summary` 及其下级页 |
| 流式、多气泡、行动步骤与 Token 显隐 | 本轮不新增入口或控件 | 保留原对话设置 | 原字段、原保存节奏与生效规则 |
| 聊天背景、通话背景、铃声 | 不迁入主页 | 保留对话设置 | 原命令与原数据 |
| 朋友圈 | 主页最后一项 | 其他既有入口不变 | 原 AI 朋友圈页 |

更多的 AI 名片和菜单结构保留。旧模型／对话设置地址继续使用已有重定向，本轮不扩展地址兼容机制，也不安排删除用户熟悉的菜单入口。

## 3. 独立上下文页面

`ContextSettings` 集中展示：

1. 按条数注入：沿用单聊／群聊与主客视角的四项条数及应用到其他 AI 的能力。
2. 固定消息起点：查看当前起点、选择、更换和取消。
3. 历史群聊：查看退出时历史，选择是否注入。

固定起点启用时，原当前单聊条数保留并暂时禁用；取消固定后恢复原数值。其他来源与群聊继续遵循原契约，不新增全局模式字段，不改摘要启停或注入规则。摘要开启时的未总结原文读取仍按摘要机制处理，不能把条数界面描述成始终裁剪所有历史。

上下文草稿、校验和离开屏障由独立页面持有；原对话设置只保留页面偏好与背景能力。无效上下文不会带入另一页的显示偏好草稿。条数失焦提交，离开或选择固定起点先完成保存；失败保留草稿，阻止该次离开。没有会话时明确不可用，不创建替代会话。

## 4. 共用页面与导航所有权

`AssistantConversationPage` 为对话设置、上下文及单聊摘要页面统一读取目标助手和其既有 canonical 会话，处理加载、失败重试与不存在状态。页面成功分支直接复用原表单，不叠加安全区、导航栏、键盘避让或第二套返回拦截。

主页和更多的摘要入口直接指向相同地址。摘要列表、一级编辑、二级编辑、任务诊断与摘要设置都按目标会话读取，不再借用 `usePreparedConversation` 切换聊天；群摘要的现有页面和业务流程不变。摘要内容、生成、领取、持久化及恢复逻辑没有复制或迁移。

具体路径和返回由 App / Host 执行。普通返回回到真实来源，查看 A 的上下文或摘要不切换原来 B 的聊天、不标记 A 已读或预加载消息。只有用户选择固定起点后，才明确导航到目标 AI 的聊天。

当前聊天仍消费已有助手提交事实，设置命令和 Repository 的边界不变。没有改数据库 schema、默认值、权限、主理关系或备份格式。

## 5. 验收与交付

- 资料卡编辑跳转、动态主页标题、300 字符预览与 Unicode 省略。

- 摘要所有下级页使用目标会话，读取失败、重试、无会话和订阅释放。
