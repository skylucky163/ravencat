# 提示词中心

首页只显示条目、用途和顺序，不展开聊天、记忆或协议正文。“先认识彼此”上方的选择器决定编辑对象：没有 AI 时显示“暂无 AI”；有 AI 时默认主理 AI，没有主理则选列表首位。携带业务 ID 打开时保留该对象。选择器只读取轻量身份列表，不改变主理关系。主聊天内置提示词统一中文，旧英文覆盖数据保留但不参与注入。

## 页面与配置所有权

概览与普通聊天编译器共同读取 `@shared/prompt` 的 `CHAT_PROMPT_READING_FLOW`，单聊、群聊、账本回应与日程唤醒按同一主线展示、编号和组装。AI 身份池位于协议之后、自定义提示词之前；MCP 简介独立位于工具目录之后。工具运行上下文在历史之后，本轮回应要求在时间之后、当前输入之前；应用触发时省略真实用户输入。通话和内部决策任务保留各自场景预设。页面不再维护第二套固定顺序。自由排序仍未开放，自定义片段只在自己的组内按保存的列表顺序排列。

- 系统基础规则直接进入单正文编辑页，只承载运行环境与通用行为边界；原独立视觉规则不再注入，也不再提供编辑页签。
- 系统基础规则允许保存空正文：空覆盖表示主动省略这一块，不回填代码或全局默认，不影响 AI 人设和其他提示词；单独保存、全局应用和安全预览使用同一语义。「恢复默认」删除覆盖后才恢复默认正文。其他内置规则和自定义片段仍要求非空。
- 「条件提示词」是独立路由页，按真实功能分组，当前只有「图片 → 图片防幻觉提醒」。默认开启，仅在未配置 OCR、聊天图片附件走直传路线时随附件追加；OCR 成功、失败、不可用以及通话快照和图片工具观察均不追加。列表提供逐条注入开关与正文入口，开关按 AI 保存。触发条件由功能负责，正文支持全局默认、AI 覆盖和恢复默认；关闭后完全省略提醒，恢复正文不改变开关。长说明复用导航栏的问号组件。
- 「按需提示」下的「其他提示词」以通用任务提示词为入口，说明不限定摘要；独立列表按功能分组，当前提供「聊天摘要 → 一级摘要提示词／二级摘要提示词／群聊一级摘要提示词／群聊二级摘要提示词」与「图片 → 图片识别提示词」。单聊两项复用 AI 覆盖、恢复默认和草稿全局应用，开关不在 Prompting 重复保存，列表显示 Chat 的生成状态，编辑页只保留正文：一级跟随自动生成，二级还需二级开启，固定消息起点时两级停用。已有摘要的注入开关不控制生成。关闭期间仍可编辑正文。群摘要没有所属 AI，两项只保存全局正文：编辑页忽略当前选中的 AI，不写 AI 覆盖、不提供全局应用。图片识别提示词同为可覆盖正文，但没有独立开关：它随该 AI 是否绑定视觉识别模型生效，输出格式由 Chat 的锁定契约固定。
- 「其他规则」是独立路由页，内置「换行规则」与「动作描写规则」，逐条开关、默认关闭，点击灰色描述进入各自正文编辑页。两条规则开启后都排在稳定提示词前缀的系统基础规则之后、AI 人设之前，顺序为换行在前、动作描写紧随；只约束普通单聊、群聊、记账回应与日程消息，不进入通话口语、摘要或内部 JSON 任务。提示词中心复用公共输入、键盘避让与主题材质；规则列表复用公共开关行，玻璃主题下由卡片材质承载。多行正文显式指定固定高度，超长内容在框内滚动。
- 无 AI 页编辑全局规则、自定义常驻提示词和普通工具默认权限，不借用任何 AI 身份；时间开关需选择 AI 后才能调整。
- AI 页编辑该 AI 的正文覆盖、自定义提示词和工具权限。AI 人设详情支持直接编辑，点击「保存」通过 Assistants 公共资料命令更新同一份人设，并返回提示词中心；AI 个人主页仍按字段自动保存。两个入口共用助手数据库正文，不另存提示词覆盖，人设不设固定字数上限且允许清空。编辑页保留未保存草稿，再次进入时读取最新正文。无 AI 默认页只读取全局配置，需要绑定 AI 的人设与协议入口无法进入；AI 人设详情路由也要求携带 AI 标识。用户人设入口跳转个人资料，由 Profile 自动保存并供所有 AI 共用。
- 自定义列表右上角添加，长按正文上下交换排序。默认常驻片段先按全局列表顺序注入，再拼接满足条件的 AI 专属片段；排序交换由 Repository 事务提交。
- AI 自定义列表提供“全局常驻提示词”管理入口，打开不携带 AI 标识的独立列表页。无 AI 时保存的内容始终可重新访问；全局列表及编辑页明确提示影响所有 AI，删除后返回专属列表仍保留原编辑对象。
- 选中 AI 后，基础规则、条件提示词、其他规则、自定义提示词、工具权限和时间开关均保存到该 AI；正文修改不会改写全局默认，恢复默认只删除该 AI 的覆盖。
- 系统基础规则、换行规则、动作描写规则、图片防幻觉提醒和两级摘要的正文页，在保存按钮上方提供左侧「恢复默认」、右侧「全局应用」。全局应用直接使用当前编辑草稿，无需先保存，一次覆盖所有现有 AI 的同一项中文正文；各自的注入或摘要生成开关、其他提示词与全局默认保持不变，之后新增的 AI 仍使用默认值。普通保存继续只作用于当前 AI。长说明放在导航栏问号中，批量正文由 Repository 的单次事务提交，失败整体回滚。
- 工具包由 Host 唯一工具注册表的用途和主理属性生成，详情仅展示工具名称、启用开关和真实 description，不展示参数 schema 或内部属性。聊天摘要查询归入记忆，语音发送单独显示为语音；展示分类不改变工具的 Feature 所有权。主理工具通常归入独立包；应用设置按明确的产品用途合在「应用设置工具」包，包内全局项仍保持主理专属权限，非主理对象不能修改这些权限。
- 工具包详情的星标按 AI 保存于 `assistant_direct_tools`，默认不点亮。点亮后作为「用户特批工具」直接暴露，无需拆包；右侧调用权限独立保存，星标不会绕过总开关、场景、身份或能力限制。无 AI 的全局默认页不配置星标。
- Kimi 官方工具包始终可查看，搜索、网页读取与猫叫祝福默认关闭；仅 Moonshot 官方 API 的 AI 可操作开关和星标。其他接口灰显并注明不可用，已保存的权限和星标单独显示为保留偏好；切回官方接口恢复，实际注入仍受总开关、单项权限和拆包规则约束。
- 工具调用页在工具包列表上方汇总当前 AI 的特批工具，默认折叠并显示数量。展开后可查看工具名称、所属工具包与单项权限状态，点击进入对应包；返回列表后按焦点刷新星标配置。标题旁的“全局应用”将点击时的普通工具星标快照覆盖到所有现有 AI（空列表会清空普通星标），不影响未来新增 AI。主理专属星标和调用权限保持不变；主理专属工具包紧随特批工具排在列表最前面。页面规则只在标题后的问号气泡里说明，正文直接是列表；工具包详情不再有顶部说明段，只保留工具卡片自身的 description。
- 单项工具的星标和权限由 application 校验主理身份，非主理 AI 不能修改主理专属配置；全局普通星标同步由 Repository 单次事务提交，失败整体回滚。
- 联网工具包默认对所有 AI 开放，包含联网搜索、网页读取和文件下载，管理入口只在工具调用列表；无需配置密钥。下载文件保存到独立的 `Download/RavenCat AI/`，不混入备份目录。
- 手机工具及网易云八工具纳入主理 AI 专属包，支持单项调用开关与星标特批。手机工具页及应用工具包详情复用同一份 AI 调用权限，不另存手机开关；系统访问事实独立读取，页面区分关闭、缺少授权、服务未连接和权限就绪，执行仍由具体能力裁决。MCP 的 AI 生效设置由 MCP 页面自行管理，不纳入这里的配置。
- AI 身份池入口打开全局名单选择页，默认全部勾选，新增 AI 默认入选。入池规则与双向隔离说明收在标题后的问号气泡里，名单占满页面可直接勾选。取消勾选后双向隔离：该 AI 不出现在其他 AI 的身份池中，它自己的请求也不注入整个身份池块；重新勾选后恢复相互可见。名单保存于 `prompt_default_switches` 的 `agent_registry:<assistantId>`，不改变模型调用或工具权限。普通聊天按共用顺序将身份目录放在协议之后，目录中同时注明每位入选 AI 的底层模型名；全部取消时省略身份池块。
- 群聊身份背景位于 AI 身份池之后、自定义提示词之前；本轮环境在历史与社交之后，统一说明单聊／群聊／通话位置和账本／日程等触发来源。冷静期作为独立的当前身份状态展示。昵称修改与一起听退出属于按发生顺序保存的历史事件，不在环境信息中重复提醒。
- 基础规则、条件提示词与其他提示词列表及正文、其他规则、AI 人设、AI 身份池、自定义列表与编辑、工具列表与工具包详情均为独立 Expo Router 页面。顶部返回、保存后返回与 Android 系统返回共用原生 Stack；返回列表后按焦点刷新，已打开编辑页的未保存草稿保留到该路由退出。

全局配置存于 `prompt_default_overrides`、`prompt_default_user_prompts`、`prompt_default_switches`。AI 正文与普通工具权限覆盖全局默认；时间状态存于 `assistant_prompt_definition_states` 的 `context.time_awareness`，每位 AI 默认开启，旧全局时间记录不再消费。自主执行时间仍必需。没有配置记录时直接使用代码默认值。

特定应用工具包的总开关独立存于 `prompt_default_switches` 的 `app_tool_package:<packageId>`，默认关闭，在手机工具页管理。关闭时 Host 从本次授权候选中移除整个包，后续提示词、目录与 schema 只消费裁剪后的集合；单项权限和星标不改写，重新开启后沿用。总开关不依附某个 AI，也不授予普通 AI 主理身份。

图片提醒、换行规则与动作描写规则复用 `assistant_prompt_definition_states` 和 `assistant_prompt_definition_overrides`，定义分别为 `input.image_grounding`（默认开启）、`output.paragraph_breaks`（默认关闭）与 `output.action_description`（默认关闭）。无 AI 时可编辑全局默认正文，开关需选择 AI 后调整。旧 `foundation.visual_grounding` 的覆盖记录保留，但不再消费，不迁移成新的图片提醒。

两级摘要正文复用现有覆盖表，单聊定义 `internal.chat_summary` 与 `internal.chat_secondary_summary` 不新增提示词状态或数据库迁移。Host 按来源 AI 解析一级／二级覆盖，再交给 Chat 的任务提示词构造；选择辅助模型不改变提示词所属 AI。群摘要使用独立定义 `internal.group_chat_summary` 与 `internal.group_chat_secondary_summary`，没有所属 AI，只读自己的全局正文，未覆盖时使用 Chat 的群默认正文并保留中立群身份；它不读任何成员或管理员的专属覆盖，修改单聊正文也不影响群摘要。普通保存与恢复、全局应用不重写已有摘要；在途请求沿用已经读取的正文，后续请求读取新正文。

图片识别正文定义为 `internal.vision_ocr`（Chat 所有），输出契约 `output.vision_ocr_plain_text` 仍锁定、不随正文覆盖改变，两者同属 `vision.ocr` 预设。正文复用同一组覆盖表：AI 覆盖优先于全局默认，都没有时使用代码内置正文；没有独立开关。它此前存在 OCR 辅助模型的 `metadataJson.taskPromptOverride` 里、按模型配置区分，现在统一由提示词中心管理，辅助模型配置只保留连接参数与采样设置。历史 `taskPromptOverride` 记录不再读取，也不做迁移。

## 装配与请求

- application 管理默认配置和 AI 覆盖。
- domain 声明配置及 Repository contract。
- infrastructure 通过 `databaseCoordinator` 读写 SQLite。
- `composition.ts` 仅供 Host 装配具体实现。
- App 路由声明页面和业务标识；Host 的 `PromptCenterRouteContent` 执行路由与焦点适配，Feature 接收受控页面及打开详情、MCP 和协议空间的意图回调，不持有路由栈。主理专属工具已在包内直接管理，不再提供重复的手机工具跳转。

实际注入契约见 [默认提示词组装](../../../docs/prompt/default-prompt-assembly.md)。局部行为验证：`node --no-warnings scripts/verify-prompt-overview.mjs`。

手机电量位于当前时间旁，按 AI 在 `assistant_prompt_definition_states` 保存 `context.device_battery` 的状态，默认开启。关闭后该 AI 的请求不读取电池；开启后每轮读取一次电量百分比和充电状态，无需系统授权。该快照由 Host 组装，不归一起听模块所有。

「当前时间」下方提供独立的「消息时间戳」开关，按 AI 在同一状态表保存 `context.message_timestamps`，默认关闭。页面说明其帮助理解消息先后与间隔、增加输入 Token，以及部分模型可能模仿格式；无 AI 时不可操作。开启后通过独立 system 元数据提供已保存的消息时间，正文与图片保持原样，不把时间写成 assistant 回复示例，也不注入时间差。该开关独立于当前时间；关闭停止额外注入，不清理已经生成的正文或既有摘要时间。
