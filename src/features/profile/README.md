# 个人资料

「我」页在「个人」下方提供「收藏」入口；Profile 只表达打开收藏的回调意图，由 App 映射路由，收藏事实与展示归 Chat 所有。

「我 → 个人」进入 Expo Router 的个人资料页，展示头像、用户名、性别、年龄、身份、地区、其他与签名。列表不使用右侧箭头；点击整行进入对应字段编辑页。用户手动修改头像和用户名的入口位于个人资料，「我」的顶部资料只展示。

应用设置工具允许当前主理 AI 修改用户头像、朋友圈封面和玻璃主题全局壁纸；各 AI 可修改自己的单聊壁纸，主理还可管理其他 AI。选择和引用仍由 Profile 提交，复用原有 CAS、媒体备份与回收；壁纸提交后广播给 Host 注入的主题展示订阅。工具参数和权限见[应用设置工具](../../../docs/application-settings-tools.md)。

「我」提供「数据管理」入口，集中展示「最近删除」（暂未开放的占位）和常驻展开的「备份与恢复」，不提供折叠操作。标题旁的问号复用共享 Help 气泡展示完整本地备份说明。「危险操作」直接展示清空入口，执行前仍需确认不可恢复的后果，确认弹窗的「永久删除」按钮使用红底白字强调。页面复用 Backup 的公共展示入口，App 装配备份 Runtime 与已有 Host 恢复出厂命令；备份与清空操作期间互斥本页入口，清理完成后的应用状态重建仍由 Host 负责。

「我」的「数据管理」下方提供「检查更新」。更新查询、版本比较和跳过记录由 Host 应用更新宿主持有，Profile 只展示宿主提供的版本与检查状态并转发点击意图。发现更高版本时入口显示红点，Tab 栏不展示更新红点。

开发环境的更新入口标记“开发版”，点击由 Host 说明更新方式，不接收公开 APK。页底分别显示当前 JS 源码的 `package.json` 版本和已安装原生包的版本／构建编号；Metro 加载新代码不会改变原生包版本。源码版本随发布计划维护，不随每个提交自动递增。预览／发布环境只显示已安装包的真实版本。

文字编辑沿用 shared/ui 的 AutoSaveDraftEditor：失焦时保存，停输不提交，返回前排空待提交内容。Host 导航装配通过 usePreventRemove 承接 Android 返回键与系统返回手势；无效输入或写入失败保留草稿，可修正或恢复已保存值，不使用保存按钮。用户名不能为空且最多 20 字；年龄允许留空，填写时只能是可安全表示的非负整数；性别及其余设定自由填写。

Profile 是唯一资料 owner，SQLite adapter 只提交本次变更字段，事务提交后广播资料更新，头像仍由既有媒体草稿与引用事务提交。新增字段保存在 user_profile，启动迁移保留旧姓名、头像与封面；数据库快照备份自然包含这些资料。

Host 的对话者身份提示词块聚合所有已填写的文字资料，不复制人设到另一张表，也不自动截断其他设定。头像供界面展示，不把本机图片 URI 当成文字提示词发送。群聊继续使用参与者目录中的用户名快照。

验证：`node --no-warnings scripts/verify-user-profile-persona.mjs`；原生相册、键盘和返回手势需真机验收，不构建 APK。
