# Wallet Presentation

Wallet 的界面层，包含首页、快捷记账、历史日/周/月视图和历史详情。

## 入口

| 位置 | 职责 |
| --- | --- |
| `../index.ts` | 其他模块唯一入口：页面、AI 工具、`ledgerRepository`、`configureWalletRuntime`。 |
| `../composition.ts` | 装配点：把用例接到仓储与聊天网关，并直接暴露无业务规则的写入命令。 |
| `../application/` | 有业务规则的用例：新增账单与排队、快捷记账、记账 AI 回复。 |
| `historyTypes.ts` | 历史列表与详情共用的时间范围、汇总和页面契约。 |

业务实体与仓储端口位于 `../domain/`，具体依赖由 `../composition.ts` 装配。本目录只
保留界面职责；SQLite 访问和 AI 回复编排不写入组件。

```ts
import { WalletScreen } from '@features/wallet';
```

## 账单编辑

首页和历史详情的账单均支持长按选择编辑或删除，删除仍需确认。编辑复用
`AddRecordModal`，可修改类型、分类、金额、备注和日期，不改变账单 ID 与创建时间。
历史分类超过五条时可展开全部记录；页面重新获得焦点后刷新账单与统计。

## 历史视图

`utils/timeUtils` 生成时间范围与卡片标题：范围从今天向前展开，最新的在前；周视图
展示日卡、月视图展示周卡、年视图展示月卡，卡片本身共用 `HistoryCard`。

列表按页追加：每页是当前视图的一个周期（一周 / 一月 / 一年），只查询尚未加载的范围。
首屏在内容高度和视口高度都已测量后判断是否补下一页，填满可视区域即停止，空周期也
作为日期卡展示。接近底部需要用户先拖动，一次拖动只追加一页。
焦点拥有查询资格：离开页面即撤销旧请求的结果，返回时立即刷新已展示范围，不等待旧
请求、不重置窗口。读取失败后暂停自动补齐，用户触底时可显式重试当前失败范围。

## 分类

分类预设集中在领域层，支出九项、收入六项。预设不是白名单：普通记账、编辑和
快捷记账都可输入自定义分类，并按收支类型复用全部账单及快捷记账中已使用的分类。
已有的 AI 自定义分类无需迁移；分类列表不受当前月份、历史详情范围或记录条数限制。
自定义分类随账单或快捷记账保存，不单独维护一份分类目录。

## 视觉

首页概览、历史视图切换器和收支详情的主要卡片复用 `ThemedSurface`。
日、周、月账单列表使用轻量主题底色与边框，不为每条记录运行原生模糊。
收支金额保持原有红绿语义色；按钮文字使用明确的前景色，不使用可能透明的页面背景色。
记账 AI 选择弹窗的标题、取消和保存固定，AI 选项在剩余高度内独立滚动。

## AI 工具与回复

Wallet AI 工具支持新增、查询、编辑、删除账单。查询与新增的模型可见结果包含真实
账单 ID；编辑只更新传入字段，删除或编辑不存在的记录返回失败。金额不明确时应先
询问用户。AI 新增复用账单新增用例，但不安排记账自动回复，避免递归触发聊天。
`getLedgerContext` 的 `keyword` 模式支持 `type`、`category`、`timeDescription`，也可用
`startDate` / `endDate` 指定精确范围；`limit` 默认 10、范围 1–50，只限制返回给模型的记录数，
命中统计仍覆盖全部匹配账目。
手动记账的延迟回复批次只保留账目 ID，派发时读取当前记账 AI 和仍存在的账目；角色
已更换或全部账目已删除时取消该批次。恢复出厂由 Host 关闭 Wallet 队列并等待派发结束，
与 Agent 取消同时进行；新 Host 完成数据库启动后重新开放，旧入队查询不能跨数据换代
重新排队。
`getLedgerContext` 的 `categories` 模式查询预设和已有自定义分类，可按 `type` 筛选；
新增和修改工具明确要求优先复用原名，具体消费内容写入备注，尽量避免另创同义分类。

快捷记账通过 `createLedgerQuickAction`、`updateLedgerQuickAction`、`deleteLedgerQuickAction`、
`useLedgerQuickAction` 管理，沿用羽库工具包的权限与按需展开。`getLedgerContext` 的
`quickActions` 模式返回模板及真实 ID，支持按收支类型、分类和名称／分类／备注关键词筛选。
创建模板不新增账单；编辑只修改传入字段，编辑或删除模板不影响已有账单。
使用模板在同一事务内读取当前模板并新增一笔账单，可指定日期，默认用户当地今天；
未填写单独备注时，生成账单以当前快捷记账名称作为备注；已有单独备注继续使用，不回写历史账单或模板。
AI 使用复用现有提交用例，不安排另一轮记账自动回复。

`sortOrder` 是排序权重，不是唯一 ID，也不要求连续。页面新增不分配排序号；
仓储在同一事务内读取当前最大权重并在末尾新增，AI 创建省略权重时沿用相同规则。
显式指定权重仍可调整位置；同权重按创建时间、唯一 ID 排序，历史同值无需重编号。
