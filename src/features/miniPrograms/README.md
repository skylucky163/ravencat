# 小程序

小程序目录负责展示入口，具体页面地址和跨页面导航由 App 路由适配拥有。

## AI 请求诊断

「小程序 → AI 工具 → AI 请求诊断」使用独立页面，展示 `@platform/ai` 保存的最近 10 条 HTTP 请求与响应。开关默认关闭，只记录开启后的请求；开关和完整记录持久保存在应用私有目录，重启、覆盖更新和清理缓存后仍保留，超过 10 条才淘汰最旧记录。关闭只停止新增，已有记录继续保留；手动清空或恢复出厂时删除，不自动上传。旧缓存中尚存的记录会迁入长期目录。列表可选取单条，记录详情在独立底部弹窗中展示，与页面上的开关和列表互不干扰；请求正文与响应正文默认分别折叠，展开后按页显示可选原文，单页约 4000 个 UTF-16 单元，不拆开代理对；原生滚动区只承载当前页，避免超长正文一次排版。重新打开详情时恢复折叠与第一页。底部独立复制完整请求正文或完整响应正文，不附加元信息，不受折叠和当前页影响；分页不解析、格式化或截断保存的 JSON / SSE，也不改变提示词或分析请求。

开启与复制时提示正文可能包含私人聊天或工具内容；清空、刷新和存储失败按实际结果展示。记录的捕获、保留和清理规则属于 AI 平台，MiniPrograms 只读取快照、订阅更新与转发操作，页面返回意图由 App 路由适配执行。
