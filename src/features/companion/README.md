# 主动伴随

AI 日程是唯一的定时自主唤醒能力，Self Wake 已退役。当前业务不变量见 [主动伴随架构](../../../docs/ravencat/proactive-companion.md)。

- `AIScheduleApplication` 校验模型输入、时间和来源。
- `SQLiteAIScheduleRepository` 在事务中维护状态机、开关及 claim。
- `AIScheduleProjectionOwner` 提交启停意图后同步 keyed Android 投影。
- 日程工具默认同时写入系统日历；缺权限在提交前报错，用户可显式选择仅内部提醒。设置入口位于「权限与后台运行」，日历副作用与 AI 唤醒共用投影 owner 的恢复入口，系统提醒不依赖应用进程存活。
- `RunHeadlessAISchedule` 取得当前主理身份与执行权后，进入 `RunHostAutonomousAgent`，复用普通单聊 Prompt、Chat 执行、工具及存档。
- 日程超过计划时间 15 分钟仍未取得执行权则永久跳过。恢复、迟到系统回调及最终 claim 共用持久终结事实，不能回到 scheduled 或补跑。
- 同批到期安排选择计划时间最新者（同时间按更新版本与 ID 排序），旧背景归入新安排。碰撞正在执行的旧日程时先撤销旧回合 fence；碰撞聊天、待回复用户输入或交付时则交给聊天，不排队启动额外模型。用户新输入仍在 T1 中优先撤销自主 owner。
- `raven_cat_ai_schedule_context` 只保存处理结果和提示词交接凭据，没有唤醒能力。失败、过期信息进入下一次普通单聊的动态交互环境；归并背景进入相应最新日程或正常聊天。按 Chat 回合 committed 确认单次告知，失败／取消保留结果，迟到绑定以 CAS 拒绝。
- 展示、行动步骤、T3 提交及交付与普通聊天共用。正文（包括工具前言）生成时就在独立气泡展示，思考及工具状态进入行动步骤；不另插入开始、响应或结束说明。隐藏触发来源只提供定位锚点，响应与终态读取共享回合和展示事实。
- 最终正文完整等于 `[[NO_MESSAGE]]` 时不追加文字，不撤回此前已展示的正文或媒体。失败／中断保留已经交付的共享展示片段，后续模型按触发来源读取历史资料，不补发未完成正文。
- `ProactiveLifeReadQueries` 从同一个短事务快照读取九个可见日期的计数与当天第一页，再组合 Chat 响应证据。运行中按开始时间、历史按实际领取时间、未执行按计划时间归属日期；日期边界由展示层按本地午夜提供。当天条目按运行中、未来、历史排列，各组内按时间与稳定 ID 分页。
- 未来、运行中和历史条目均可打开日程详情，查看创建、计划与实际开始时间；未领取的安排显示尚未开始。
- 「权限与后台运行 → 日程运行诊断」按需读取并复制原生记录。最近 80 个阶段按 delivery identity 区分，覆盖闹钟到达、Worker、执行期前台服务、Headless 启动与宿主收口，并保存阶段发生时的 Doze、省电与电池优化状态。诊断不调度或执行日程，存储故障不影响业务；旧版本过程无法补录，缺少某阶段也不能直接当作未发生。

关闭主动伴随暂停并保留计划；重新开启只恢复未来安排，错过的不补跑。已取得执行权的 run 由当前有界执行宿主收口。中断保留已经存档的模型输出与步骤，不重放行动。

跨 Feature 依赖公共根出口，具体装配使用 `composition.ts`。原生运行时与 Overlay FGS 独立；开关不能建立常驻服务。

## 时间碎片界面

`ProactiveLifeScreen` 使用开放弧线承载日期。`ProactiveLifeCalendarArc` 只保留九个日期节点，Reanimated UI 线程只更新位移、大小、旋转和透明度；同一天保留原生图片与蒙版实例，只在屏幕外增删边缘日期，避免跨日时可见照片换源而闪烁。停稳后提交日期选择并查询当天安排。日期与真实星体素材的映射稳定，任意九个相邻日期不会重复素材。照片来源及取景见[素材说明](presentation/assets/fragments/README.md)。

星云、星点与低分辨率滤镜预算归 `shared/ui/space`，记忆与伴随各自拥有手势和生命周期；两者不互相依赖。伴随页的玻璃只采样不透明星空，正文与弹层都在采样源外，避免背景文字被再次折射进日程和日期跳转窗口；保留原有玻璃材质参数。Screen 在失焦、后台、弹层打开或系统要求减少动态效果时暂停装饰动效。日程详情仍使用唯一查询与 projection-aware 取消命令。输入日期复用公共字段和弹层键盘避让。

页面只保留当前日期窗口，不为无限日期累计元素或缓存；迟到的查询和分页由当前读取代次隔离。

`ProactiveLifeArcLights` 在照片之外绘制二十个有界光点：沿弧线缓慢移动的流光、微弱闪烁的星尘与选中位置的单次柔光。装饰共用一只 UI 线程时钟，只更新变换和透明度，不改写照片或蒙版；失焦、后台、弹层与减少动态效果共用弧线的暂停边界。

可见的最多五块碎片以 100～140 秒一圈缓慢平面自转，日期文字保持正向。旋转只更新照片外层的 transform，不重新生成图片与蒙版；节点移出弧线可见范围、日期区域滚出页面或页面暂停时停止动画。流星复用 `shared/ui/space/ShootingStars`，与记忆页共用同一生成器和单条飞行效果，最多一条，暂停时清除计时器并取消飞行。
