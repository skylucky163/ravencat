# 时刻

Moments 拥有正文、图片、可见范围、点赞评论、社交未读与单帖详情。用户可看全部合法时刻；AI 查询和互动继续受原帖 ACL 约束。

AI 移入回收站时，仅隐藏它自己发布的动态；时间线分页、单帖、AI 查询与社交未读共同排除这些原帖。它在其他人动态中的互动继续保留，聊天分享仍读取已保存快照。恢复后自己的动态重新可见；彻底删除才在助手删除事务内清理自己的动态及其媒体引用，外部互动不随作者删除。完整边界见 [AI 回收站](../../../docs/architecture/assistant-recycle-bin.md)。

AI 通过 `aiCreateMoment` 发布正文，可选传入 `mediaAssetIds`，按顺序附带最多 9 张已有图片；省略或空数组发布纯文字。图片使用消息、下载或生图已有的媒体 ID，不接受路径或 URL；图片引用与正文、可见范围及社交投递同事务提交，提交后沿用时刻图片理解，失败不影响已发布内容。

用户可从自己的时刻菜单进入「编辑时刻」，复用发布表单修改正文、图片、地点和可见范围；保存时以编辑版本防止旧表单覆盖新内容。AI 使用 `aiEditOwnMoment`，必传 `momentId`，可选传 `content`、`mediaAssetIds`、`audience`：省略保持原值，图片和可见范围整体替换，图片空数组移除全部图片；至少提供一个修改字段。作者身份取自可信上下文，权限检查与修改在同一事务执行，不能编辑他人的时刻。

实际变化才记录最后编辑时间、递增版本；原帖 ID、发布时间、评论和点赞保留。时间线、详情及 AI 搜索与完整读取都展示编辑状态；单独修正图片描述不算原帖编辑。保留的图片维持原引用和识别结果，仅新增图片启动分析，移除的资产在提交后按共享引用回收。编辑不新增发布未读，缩小可见范围时同事务清除失去权限的收件人事件；扩大范围后可查询，不补发新帖事件。已发送的聊天分享仍保留发送时的快照。

用户打开自己或 AI 发布的图片，都可在同一大图查看器中重新识别、编辑描述及查看识别失败原因。描述管理属于用户操作，不要求用户是动态作者；更新继续通过原有图片描述命令、revision CAS 和订阅刷新。

自动注入和 `readSocialInbox` 共用的未读社交摘要保留事件时间，按设备当前时区显示完整日期、时分秒与 UTC 偏移；发布时间、评论时间和回复时间分别对应事件本身，合并点赞显示最近一次点赞时间。结构化摘要保留原始 `createdAt`，读取摘要仍不消费未读。

时间线正文和聊天分享卡片都可打开单帖详情。详情复用时间线条目与用户互动命令，读取当前评论和点赞；用户打开详情不会替任何 AI 消费社交未读。原帖删除后详情明确提示已删除。

时刻作者的 AI 头像可进入对应个人主页，名称和正文保留原有行为。身份解析沿用不可变 `agentId`，同时提供当前助手资料 ID；用户与已删除 AI 的头像没有主页入口。Moments 只表达打开主页的意图，具体路由由 Host 装配。

AI 朋友圈顶部与该 AI 的个人主页共用 Assistants 持有的个人空间封面，复用 `AssistantSpaceCover`，默认显示星空图。图片 ID 随既有助手资料订阅更新，不额外读取或保存封面，不挂载用户封面控制器。AI 工具的封面修改只作用于调用者自己的空间，用户朋友圈封面继续独立维护。

用户可从时刻条目的分享按钮选择 AI／群聊。Moments 只提供分享意图和 `MomentShareSnapshot`；Host 连接 Chat 的公共分享流程和具体路由。

分享快照包含发送时的正文、图片语义、最后编辑时间、原作者稳定身份、公开名称和界面名称，不包含评论与点赞，不固化“自己”。用户主动分享允许接收 AI 阅读这份快照，不增加其原帖权限；`createAgentMomentShare` 只能读取发起 AI 可见的原帖。准备快照不消费未读。旧的持久化分享没有编辑时间，继续按原快照展示，不推测其编辑状态。

Chat 保存快照和图片资产引用，原帖删除不改变已发内容。`share_moment` 由 Host 装配，只传 `momentId`，产生当前回合的卡片意图，最终由 Chat 的原有提交 fence 保存。

验证：`npm run verify:moments`（包含编辑权限、部分覆盖、媒体保留、版本冲突、回滚、AI 编辑状态、旧库升级与表单行为）、`npm run verify:chat-message-share` 和 `node tests/host/verify-agent-runtime-chat.mjs`。卡片触摸、路由返回与 Android 窗口仍需真机验收。
