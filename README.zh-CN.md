# RavenCat

[English](README.md) | **简体中文**

**开源 Android 多模型 AI 聊天客户端。**

RavenCat 在同一 Android 应用中集成可配置的模型服务、单聊与多 AI 群聊。你可以为不同的 AI 设置名字、人设和模型，对话记录与设置保存在本地。

项目基于 **React Native、Expo、TypeScript 和 SQLite** 构建，将对话界面、记忆管理、本地数据持久化与 Android 原生模块结合起来。这是一个面向日常使用、探索可定制 AI 交互的个人项目。

除文字聊天外，项目还包含可配置的语音与视频通话、悬浮交互、日程任务以及本地备份与恢复。当前功能范围见下方清单与相关技术文档。

这是一个个人维护、持续开发中的项目。部分后台行为和跨设备恢复还需要更多真机验证，尚未确认在所有手机上的可靠性。

公开安装包下载见 [GitHub Releases](https://github.com/skylucky163/ravencat/releases)，各版本的发布状态以对应发行版页面为准。[v2.2.0 更新说明](docs/releases/v2.2.0.md)。

固定消息上下文起点：固定后，起点至最新消息的全部原文进入上下文，自动生成摘要暂停；对话增长可能增加 Token 消耗并超出模型的上下文额度。取消固定后，自动生成摘要需手动重新开启。

## 可以做什么

- **聊天与群聊**：管理多个 AI，发送文字、图片、文件和语音，使用引用回复、贴纸和消息翻译。
- **人设与记忆**：设置个人资料和 AI 人设，管理对话记忆与提示词，让交流更贴近自己的习惯。
- **语音与视频电话**：和 AI 通话，配置语音识别、合成语音和相机画面。
- **悬浮交互**：在其他应用上方打开悬浮球，快捷聊天、摘录和截图。
- **主动陪伴与日程**：允许 AI 在后台按计划执行任务、发送主动消息；开启主动陪伴不要求同时开启悬浮球。
- **生活功能**：时刻、记账、一起听歌，以及按需授权的手机工具和 MCP 外部工具。
- **本地备份**：导出聊天、媒体和设置，并从备份恢复。

使用、开发和各功能的当前架构入口见[文档导航](docs/README.md)。专项技术文档目前主要使用中文。Android 后台、跨设备恢复与真实外部服务的验证范围在对应专项文档说明。

## 使用前需要知道

目前只支持 **Android 13 及以上**。项目包含自定义原生模块，不能直接用 Expo Go 运行，也没有 iOS 版本。

RavenCat 不附带免费的模型服务或 API Key。你需要在应用中配置自己使用的模型服务；通话、翻译等功能还需要对应服务的凭据，费用由服务提供方收取。

聊天、媒体和设置保存在手机本地。使用模型和外部工具时，相应内容会发送到你配置的服务；截图、相机和手机工具的使用也取决于你开启的功能与授权。中文 OCR 使用 Google ML Kit，其输入处理在设备上完成，SDK 可能向 Google 发送性能和使用指标，详见[Google 官方条款与隐私说明](https://developers.google.com/ml-kit/terms)。

单聊可以通过摘要压缩较早的对话，或在关闭自动摘要且未固定起点时按设置读取近期消息；这些上下文设置不会删除本地聊天记录。具体行为见[对话两级摘要](docs/architecture/chat-summary.md)。

本地全量备份**不加密，并包含服务凭据**。请把备份当作私人文件保管，分享日志或提交问题时也不要附上 API Key、聊天数据库、备份或个人截图。

## 从源码开始

准备 Node.js 22（`>=22.23.4 <23`）、Android 开发环境和一台 Android 13+ 手机或模拟器，然后安装锁定的依赖：

```powershell
npm ci
```

第一次运行需要编译并安装包含原生模块的开发版：

```powershell
$env:EAS_BUILD_PROFILE = 'development'
npx expo run:android
```

以后通过 USB 连接手机时，可以启动开发服务器：

```powershell
adb reverse tcp:8081 tcp:8081
npm start
```

默认通过 localhost 连接，不需要 Tailscale 或维护者的 Expo 账号。该连接参数不限制服务器监听网卡；局域网、Tailscale、开发端口访问限制及 EAS 云构建见[本地开发指南](docs/development.md)。
